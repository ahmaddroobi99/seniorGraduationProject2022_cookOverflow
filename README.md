# CookOverflow — BSc senior project (Django)

**BSc senior graduation project, 2022.** CookOverflow is a recipe web app:

- Django site with accounts (`Account/`), recipes, and related apps
- R&D on a **recipe search / recommender** (`AI_Search_RecommenderSystem_R&D/`, notebooks + a recipe-box scraper)
- Raw recipe JSON dumps from Allrecipes / Epicurious / Food Network-style sources

Companion mobile client: [cookoverflow_Mobile_GradProject_2022](https://github.com/ahmaddroobi99/cookoverflow_Mobile_GradProject_2022).

Undergraduate capstone — not current research.

**Stack:** Python, Django, Jupyter, scrapers
